# KNU 곰두리 스마트맵 (프로토타입)

강원대학교 춘천캠퍼스 길찾기 웹 지도입니다. 2026 ACE-COLLABORATION 공모전 출품 준비용 시제품입니다.

- 바로 열기: https://lyw012012-cpu.github.io/knu-map/
- **조감도** 화면: 조원이 만든 v1.0 (건물 번호를 누르면 층별 정보)
- **실제 지도** 화면: OpenStreetMap 보행로 위에서 최단 경로와 효율 경로(오르막·계단 반영)를 비교
- 팀 작업용 도구: 효율 계산 값 수정, 강원대생 길·고도점 현장 입력, 데이터 저장/불러오기

## 파일
- `index.html`: 현재 버전 (v1.1)
- `campus_map.jpg`: 조감도 그림 (강원대학교 공식 캠퍼스맵, 사용 허가 확인 필요)
- `vendor/`: Leaflet 1.9.4 (BSD-2-Clause)
- `prototype_v0_1.html`: 실제 지도만 있는 이전 시제품
